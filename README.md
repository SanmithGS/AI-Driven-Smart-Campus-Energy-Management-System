# AI-Driven Smart Campus Energy Management System
### 🏆 Hitachi INNOTHON 3.0 — 4th Place (Consolation Prize) | ₹10,000 Cash Award
### Team Jayanova | NIT Warangal | March 2026

## Overview
An AI-powered Energy Management System for smart campuses combining 
ANN-based load/solar forecasting, intelligent BESS dispatch, 
anomaly detection, and real-time monitoring — validated on both 
MATLAB Digital Twin and ESP32 hardware prototype.

## Key Results
| Metric | Value |
|---|---|
| Peak Demand Reduction | ~18–22% |
| ANN Forecast R² | >0.97 |
| Anomaly Detection | 3-sigma, sustained fault confirmation |
| Battery Round-trip Efficiency | 92.15% (η_c=0.95, η_d=0.97) |
| BESS Payback Period | 5.8 years |
| Solar CO₂ Offset | 2052 tonnes/year |

## System Architecture
- ANN Load Forecasting: 15-10 neuron feedforward network
- ANN Solar Forecasting: 8-neuron feedforward network  
- BESS Dispatch: AI rule-based with dynamic peak threshold
- Fault Detection: 3-sigma anomaly detection with 3-step confirmation
- Hardware: ESP32-based physical prototype with real-time dashboard

## Tools
MATLAB/Simulink | ESP32 | Arduino IDE
